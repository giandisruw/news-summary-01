# News Summary — 11 November 2026

Entry for the make.fun bounty **"Write the best summary of 11 November's world news"** (news-summary-01, $200 USDC).

## What it is

`main.py` (Python 3.13, standard library only) writes a summary of the
world's news of Wednesday 11 November 2026 to `/output/entry.txt`. The
summary is a fixed text held in this repository: the program runs with no
network, and both runs write the same bytes (1,838 characters, UTF-8).

## The summary

Covers the day's major stories: the Iran war and the Strait of Hormuz
(tankers on fire, Rubio's statement, Bessent threats, DOJ charges);
Ukraine-Russia-US talks in Abu Dhabi and the prisoner exchange; Gaza and
Israel's hung parliament; Yemen; COP31 in Antalya; the Ebola outbreak in
the Democratic Republic of Congo; US politics (Hegseth impeachment killed,
Jim Jordan as minority leader); a US Army officer arrested in Britain on
suspicion of spying for Russia; and Anthropic's $1.4 trillion listing.

## Run it

```sh
python3 main.py        # writes /output/entry.txt
```
